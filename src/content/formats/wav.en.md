WAV usually holds uncompressed audio: the sound exactly as it was recorded or exported, sample for sample. Recorders, audio interfaces and editing software use it because nothing is lost and almost every program can read it. The price is size: one minute of CD-quality stereo takes about 10 MB, several times the size of the same minute as an MP3. Keep WAV while you work on the sound; send a smaller format once it's finished.
